### 週次（`period = 2026-W33`）

````text
あなたはAI動向のリサーチャーです。対象期間 2026-W33（2026-08-10〜2026-08-16。ISO週・月曜始まり）に公開されたAI関連ニュースを収集してください。

■ 収集のしかた（厳守）
- **必ず web 検索を使って実在の記事を集めること。** 記憶や推測で記事・URL・公開日を書かない。
- 対象期間（2026-08-10〜2026-08-16）に**公開された**記事を集める。
- 収集日は 2026-08-17（本日）。

■ 収集対象の優先ソース
TechCrunch / VentureBeat / Ledge.ai / ITmedia / 各社公式プレスリリース / 政府・公的機関発表。
その他でも信頼できる主要・専門メディアは可。個人ブログ・SNS単独・まとめアフィリエイトは収集しない。

■ 収集範囲の観点（次の7カテゴリを網羅するよう広く）
- 主要AI企業・モデル動向（ai_major_company_model） — 主要企業、基盤モデル、生成AIプロダクト、AI基盤技術に関する重要な発表・変更
- AIエージェント・業務自動化（ai_agent_automation） — AIエージェント、自律型AI、業務プロセス自動化、ワークフロー自動化に関する情報
- AIガバナンス・法規制・リスク（ai_governance_risk） — AI利用ルール、法規制、セキュリティ、著作権、個人情報、リスク管理に関する情報
- 企業AI活用事例（enterprise_ai_case） — 国内外企業によるAI導入・活用・業務改善・社内展開の具体事例
- 業界別AI動向（industry_ai_trend） — 特定業界におけるAI活用、導入傾向、競争環境、業界課題との接続に関する情報
- AI人材育成・組織変革（ai_training_org_change） — AI研修、リスキリング、AI推進組織、CoE、社内展開、チェンジマネジメントに関する情報
- AI導入・運用ノウハウ（ai_implementation_ops） — AI導入、PoC、本番運用、評価、ROI、品質管理、定着化、内製化に関する実務情報
- 「今週」の新規性を重視する（対象期間に新しく出た動きを優先する）。

■ この段階でやらないこと
- スコアリング・除外判定・タグ確定はしない（次段の責務）。ここは網羅的に集めることに徹する。
- 重複しうる記事もこの段階では落とさず全て残す（次段で統合判定する）。

■ 各記事に入れる内容
- collected_at: 収集日（本日 = 2026-08-17）
- published_at: 公開日（わかる範囲。分からなければ null）
- title: 記事タイトル
- url: 記事の URL（正規化前でよい）
- source: 媒体名
- raw_summary: 本文から2〜4文の客観要約（意見を混ぜない）
- region_hint: 日本 / 海外 / グローバル / 不明
- primary_or_secondary: 一次(公式) / 報道 / 不明
````
